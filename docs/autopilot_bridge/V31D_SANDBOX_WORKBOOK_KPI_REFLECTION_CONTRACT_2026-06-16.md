# V31D Sandbox Workbook KPI Reflection Contract

This patch adds a dry-run contract for sandbox workbook KPI/readiness reflection.

## Purpose

V31D defines the fields that can later be reflected into a sandbox workbook or KPI panel after source evidence and downstream consumer contracts are reviewed.

## Governance

- Production automation remains OFF.
- Forecast gate remains OFF.
- Model promotion remains false.
- Stable engine is not modified.
- Canonical workbook is not overwritten.
- No workbook write is performed.
- Race Predictions, Fantasy, forecast bundle, and notification consumers remain disabled.
